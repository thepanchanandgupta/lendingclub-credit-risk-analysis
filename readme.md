\## Dashboard



\### Main Dashboard



!\[Dashboard Overview](images/dashboard\_main.png)



The main dashboard summarizes key portfolio metrics including total applications, loan disbursement, default rate, and interest rates. It also visualizes portfolio composition, borrower behavior, and credit risk drivers.



\### Loan Applications Over Time



!\[Loan Applications Trend](images/loan\_applications\_over\_time.png)



This visualization shows the rapid growth of the LendingClub platform, where applications increased from around 1,000 in 2007 to nearly 500,000 by 2018, reflecting the adoption of peer-to-peer lending.
